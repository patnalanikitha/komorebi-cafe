# ☕ Komorebi Café — A Cozy Barista Experience

An interactive coffee brewing simulator and UI/UX showcase built with **React**, **TypeScript**, **Tailwind CSS**, and the **Web Audio API**.

---

## Features

- **12 Authentic Coffee Recipes with Custom Pixel Badges:**
  - *Espresso, Black Coffee (Drip), Americano, Long Black, Cappuccino, Latte, Flat White, Macchiato, Cortado, Mocha, Affogato, Cold Brew.*
- **Custom Pixel-Art Icons & Ratio Bar Anatomy:**
  - Detailed recipe dossier with layered visual ratio progress bars.
- **Dynamic Barista Workstation:**
  - Contextual tools that adapt to the targeted recipe (Espresso levers, Gooseneck kettle, Milk steam wand with Oat/Whole/Almond milk & froth controls, Gelato scooper, Ice cube dispenser, Chocolate fudge pump, and Garnish shelf).
- **Interactive Cup Visualizer:**
  - Live animated SVG/CSS cup rendering 5 distinct vessels with multi-layer liquid fills and rising steam particles.
- **Procedural Sensory Audio (100% Offline via Web Audio API):**
  - Procedural rain soundscape against the window with volume slider.
  - Portafilter click & espresso machine extraction hiss.
  - Water pour trickle & steam wand frothing hiss.
  - Ceramic cup clink & brass service bell chime.
- **Diegetic Customer Order Slips & Free Brew Sandbox:**
  - Pinned order tickets with regular guests (Luna, Sam, Milo, Elena, Kenji) and free sandbox crafting.
- **Postcard Tasting Feedback & Confetti:**
  - Order accuracy scoring, customer dialogue, and unlocked barista stamps.

---

## Getting Started

To run the café locally:

```bash
# Install dependencies (if not already installed)
npm install

# Start local development server
npm run dev
```

Open your browser at `http://localhost:5173`.
